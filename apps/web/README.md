# Reference UI

**Status: not yet implemented.** Next.js.

Two screens are load-bearing architecture rather than presentation:

**Ranked candidate confirmation.** The published benchmark for this task shows 90.1% code
accuracy against 75.5% end-to-end success — the gap is presentation, not retrieval.
"None of these" is a designed route into a clarifying question or a staff referral, not
an error state.

**The evidence tree.** Every determination renders as the predicate tree that produced
it, annotated with truth values and citations. A determination a user cannot interrogate
is a determination they cannot appeal.

Accessibility is a requirement, not polish: WCAG 2.2 AA, Section 508, and a plain-language
reading-level target. See `docs/14-nfr.md`.
