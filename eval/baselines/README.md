# Baselines

Committed baselines. CI fails on regression against these.

**Every file here is currently an honest placeholder**, clearly marked, carrying no
numbers. A baseline file containing invented figures would be worse than an empty one: it
would make the gate appear to pass while measuring nothing, and the first real
measurement would look like a regression.

Real baselines land with the vertical slice, produced by the harness against the
adjudicated fixture set, and every entry records the fixture-set version it was measured
against.
